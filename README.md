# Fruit Processing Digital Consultant

 ## Purpose:
This project helps entrepreneurs plan fruit processing units by collecting business inputs, analyzing feasibility, and generating a Digital Project Report (DPR) using AI.

## Problem Statement:
Manual DPR preparation is time-consuming, error-prone, and requires expert consultation.

## Proposed Solution:
A web-based system that collects user inputs, processes data using business logic & AI, and generates a structured DPR after admin approval.

Technology Stack
Frontend
		Html, css, js, SSR (Server side Render) 
	Backend
Node.js + Express js - REST APIs, Business Logic 
MongoDB 
AI / LLM -  (For DPR Content generation)
Google form + excel sheet
